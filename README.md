# AI Stylist 👗✨

AI Stylist is a SwiftUI-based iOS application that helps users build outfits, manage their wardrobe, and get smart styling suggestions powered by AI.

## ✨ Features

- 👕 **Wardrobe Management**
  - Add and organize clothing items
  - Categorize by type (tops, bottoms, shoes, etc.)

- 🧠 **AI-Powered Outfit Creation**
  - Upload a photo and let AI identify clothing items
  - Smart outfit suggestions based on context

- 🧳 **Travel Capsule Planning**
  - Build mix-and-match outfits for trips
  - Minimal, efficient packing suggestions

- 📅 **Outfit Calendar**
  - Plan daily outfits
  - Visual weekly calendar view

- 🔐 **Authentication**
  - Google Sign-In via Supabase
  - Secure session & access token handling

## 🛠 Tech Stack

- **SwiftUI** (iOS 15+)
- **MVVM Architecture**
- **Supabase**
  - Authentication
  - Session management
- **Async/Await**
- **REST API integration**
- **Custom UI Components**

## 📱 Requirements

- iOS 15.0+
- Xcode 15+
- Swift 5.9+
